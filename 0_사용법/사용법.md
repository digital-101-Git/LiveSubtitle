# LiveSubtitle 간단 사용법

## 첫 사용자(앱만 있는 경우): 앱 구동 설정

**모델 파일이 없는 경우, 먼저 모델을 다운로드해 지정된 폴더에 넣어야 합니다.** 아래 경로는 `LiveSubtitle.exe`가 있는 앱 폴더를 기준으로 합니다.

1. 아래 **검증된 모델 다운로드** 표에서 로컬 **음성 인식 모델 1개와 한국어 번역 모델 1개**를 다운로드합니다.
2. 다운로드한 파일을 아래 위치에 넣습니다. 폴더가 없으면 같은 이름으로 만드세요.

| 다운로드한 모델 | 넣을 위치 |
|---|---|
| Qwen3-ASR-1.7B | `models/asr/qwen3-asr-1.7b/` |
| Whisper large-v3-turbo | `models/asr/whisper-large-v3-turbo/` |
| 한국어 번역 모델의 `.gguf` 파일 | `models/translation/` |

음성 인식 모델은 **가중치·설정·토크나이저 파일을 함께** 해당 폴더에 넣으세요. 다운로드 폴더를 한 겹 더 넣지 말고, `config.json` 등이 위 경로 바로 안에 있도록 합니다. 번역 모델은 `.gguf` 파일을 **원래 파일명 그대로** 넣으면 됩니다.

3. **LiveSubtitle.exe**를 실행하고 두 모델을 각각 선택한 뒤 **모델 준비**를 누릅니다. 준비가 끝나면 아래 실행 순서에 따라 방송 자막을 시작합니다.

## 실행

1. 앱 폴더의 **LiveSubtitle.exe**를 실행합니다. Ollama·Python을 따로 실행할 필요는 없습니다.
2. **오디오 소스**에서 재생 중인 Chrome·Edge, **시스템 전체 소리**, 또는 **마이크 · 장치 이름**을 선택합니다. 마이크를 새로 연결했다면 목록 옆 새로고침을 누르세요.
3. **로컬 음성 인식**을 선택하고 음성 인식 모델과 번역 모델을 고릅니다.
4. **입력 언어**를 한국어·영어·중국어·일본어 중에서 지정합니다. 자동 감지를 선택하면 모델이 언어를 판별합니다.
5. 바로 아래 **번역 언어**에서 한국어·영어·중국어·일본어를 선택합니다. 기본값은 **한국어**이며, 선택값은 다음 실행에도 유지됩니다.
6. **모델 준비**가 끝나면 **실시간 자막 시작**을 누릅니다.

- 오른쪽 상단의 **Language**에서 화면 언어를 **한국어 · English · 中文 · 日本語**로 바꿀 수 있습니다. 메뉴·안내문과 입력/번역 언어 목록의 이름이 즉시 바뀌고 다음 실행에도 유지됩니다. 자막 실행 중에도 바꿀 수 있으며, 선택한 입력·번역 언어와 실제 자막 내용은 바뀌지 않습니다.
- 오디오 소스·모델·입력 언어·번역 언어를 바꿀 때는 먼저 **중지**를 누릅니다. 입력 언어와 번역 언어가 같으면 인식한 원문을 자막으로 표시합니다.
- **음성 확정 방식**의 **기본**은 기본 인식·표시 방식입니다. **반복확인(느림)**은 여러 인식 결과를 비교한 뒤 표시하므로 더 늦어질 수 있으며, 인식 오류가 남을 수 있습니다.
- 마이크 모드에서는 선택한 입력장치의 소리를 사용합니다. 입력이 안 되면 장치 연결과 Windows의 마이크 접근 권한을 확인하세요. 마이크 자막은 기본적으로 모니터에 표시되며 위치·크기를 편집할 수 있습니다.
- 앱은 자막이 나오는 동안 계속 실행되어야 합니다. 창을 닫으면 트레이에 남으며, **완전히 종료**로 끝냅니다.
- **최근 자막**의 번역·원문은 읽기 전용입니다. 마우스로 글자를 선택하고 **Ctrl+C**로 복사할 수 있습니다.
- 상단 **번역 기록 삭제**를 누르면 `logs` 폴더의 번역 기록·로그 파일과 화면의 최근 자막을 지웁니다. 실행 중인 자막은 계속 처리되며 이후 새 기록은 다시 저장됩니다. 삭제하지 못한 파일은 진행 기록에 표시됩니다.
- Gemini 전사를 쓰려면 **Gemini Live**를 선택하고 API 키를 입력합니다. 선택한 오디오 소스의 음성은 Google로 전송되고 번역은 선택한 로컬 모델이 처리합니다.

## 음성 인식 힌트

힌트는 음성 인식 모델에 **등장인물 이름의 원문 표기**를 알려주는 기능입니다. 비슷한 발음 때문에 이름을 다른 글자로 받아쓰는 오류를 줄이는 데 도움을 줄 수 있습니다. **로컬 Qwen3-ASR에만 적용**되며, 한국어로 이름을 옮기는 방식은 번역 모델이 결정합니다.

1. 자막이 실행 중이면 **중지**를 누릅니다.
2. **음성 인식 힌트 · 선택 사항**에 이름을 **해당 언어의 원문으로, 한 줄에 하나씩** 입력합니다.
3. **음성 인식 옵션 저장**을 누른 뒤 **실시간 자막 시작**을 누릅니다.

**최근 자막의 원문에 인물 이름이 나오면**, 해당 이름을 마우스로 선택해 **Ctrl+C**로 복사한 뒤 힌트 입력란에 **Ctrl+V**로 붙여넣으세요. 이름마다 줄을 바꾸고, 잘못 인식된 이름은 올바른 원문 표기로 고쳐서 저장하세요.

샘플 중국어 영상의 인물 이름 입력 예시:

```text
顧小糖
陸擎淵
```

- 위 예시처럼 이름만 입력하세요. 번호·따옴표·한국어 풀이를 붙일 필요는 없습니다.
- 해당 방송에 실제로 나오는 이름을 넣고, 다른 방송으로 바꾸면 필요한 이름으로 수정하세요.
- 최대 **32개**, 이름 하나당 **48자**, 전체 **512자**까지 입력할 수 있습니다.
- 비워 두면 힌트 없이 인식합니다. 입력한 이름을 항상 정확하게 인식하는 것은 아닙니다.

## 자막 위치

- 기본값은 **브라우저에 표시**입니다. 메뉴 없는 팝업에서는 **모니터에 표시**를 사용하세요.
- **자막 위치·크기 편집**을 켜고 자막을 드래그하거나 크기를 조절합니다. 위치·크기는 다음 실행에도 유지됩니다. 조절한 뒤 편집을 끄세요.
- **브라우저에 표시 / 모니터에 표시**를 누르면 위치와 크기가 기본값으로 돌아갑니다.
- 모니터 표시의 기본값은 가로 중앙, 자막 하단이 화면 높이의 95%인 위치입니다.

## 검증된 모델 다운로드

이 앱에서 로딩·추론을 확인한 모델입니다. 번역용 모델은 하나만 선택해 사용합니다.

| 용도 | 검증된 모델명 | 다운로드 링크 |
|---|---|---|
| 음성 인식 | Qwen3-ASR-1.7B | [모델 폴더](https://huggingface.co/Qwen/Qwen3-ASR-1.7B-hf/tree/bcd2b5b7f32b480ab5790554cfa8347f246a14f3) |
| 음성 인식 | Whisper large-v3-turbo · faster-whisper 형식 | [모델 폴더](https://huggingface.co/dropbox-dash/faster-whisper-large-v3-turbo/tree/0a363e9161cbc7ed1431c9597a8ceaf0c4f78fcf) |
| 한국어 번역 | HY-MT2-7B · Q6_K | [GGUF 파일 다운로드](https://huggingface.co/tencent/Hy-MT2-7B-GGUF/resolve/ab8472660ac61fac25f1af43fac2599d52a8a775/HY-MT2-7B-Q6_K.gguf?download=true) |
| 한국어 번역 | MiLMMT-46-12B-v1.0 · i1-Q4_K_M | [GGUF 파일 다운로드](https://huggingface.co/mradermacher/MiLMMT-46-12B-v1.0-i1-GGUF/resolve/0d63dcbbc3e011bb2728c36769b991cd0109a2dc/MiLMMT-46-12B-v1.0.i1-Q4_K_M.gguf?download=true) |
| 한국어 번역 | TranslateGemma 12B · Q4_K_M | [GGUF 파일 다운로드](https://huggingface.co/bullerwins/translategemma-12b-it-GGUF/resolve/d7d1d8cc4ff53d4bc883ef33eae3894f07833b63/translategemma-12b-it-Q4_K_M.gguf?download=true) |
| 일본어→한국어 번역 전용 | ja-ko-vn-12b-v2 · Q4_K_M | [GGUF 파일 목록](https://huggingface.co/hell0ks/ja-ko-vn-12b-v2-gguf/tree/main) |

**JA-KO-VN은 입력 언어를 일본어(또는 자동), 번역 언어를 한국어로 선택하세요.** `ja-ko-vn-12b-v2-Q4_K_M.gguf`처럼 원래 파일명을 유지하면 앱이 일본어 원문만 보내는 전용 번역 방식을 자동 적용합니다. 다른 언어 조합에는 HY-MT2 등 다국어 모델을 사용하세요. 위 표는 로딩·출력 동작을 확인한 목록이며 모델 간 정확도 순위는 아닙니다.

## 모델 파일 넣는 위치

```text
LiveSubtitle/
├─ LiveSubtitle.exe
├─ models/
│  ├─ translation/            번역용 .gguf 파일
│  └─ asr/
│     ├─ qwen3-asr-1.7b/      Qwen 모델·설정·토크나이저 파일
│     └─ whisper-large-v3-turbo/  Whisper 모델·설정·토크나이저 파일
└─ 0_사용법/
   └─ 사용법.md
```

- 번역 GGUF는 `models/translation`에 넣거나 앱의 **번역 모델 추가(GGUF)**로 추가합니다. 전용 번역 방식이 파일명으로 선택되므로 **원래 파일명을 유지**하세요.
- GGUF 파일이 목록에 나타나는 것과 번역 방식이 맞는 것은 별개입니다. 검증 목록에 없는 전용 번역 모델은 입력 형식에 맞춘 앱 지원이 추가로 필요할 수 있습니다.
- 음성 인식 모델은 링크의 모델 폴더에서 가중치와 설정·토크나이저 파일을 함께 받아 해당 폴더에 넣습니다. 가중치 파일 하나만 받으면 실행되지 않습니다.
- 모델을 넣은 뒤 앱을 다시 실행하거나 **다시 연결**을 누르고 목록에서 선택합니다. MiLMMT·HY-MT2에는 별도의 사고 모드 해제 설정이 필요 없습니다.
- 다른 PC로 옮길 때는 앱 폴더 전체를 복사하고, 용량이 큰 `models` 내용은 제외한 뒤 위 링크에서 다시 받아도 됩니다.
- 최근 100개 번역 기록은 `logs/caption-history.json`에 원문·번역문·입력 및 번역 언어로 저장됩니다.
