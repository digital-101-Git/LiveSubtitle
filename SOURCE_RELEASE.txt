1. 프로젝트 라이선스
------------------------------------------------------------
LiveSubtitle에서 직접 작성한 코드와 문서는 MIT License로 공개합니다.
루트 LICENSE의 저작권 고지와 허가 문구를 유지하면 상업적 이용, 수정 및 재배포가
가능합니다. 프로그램은 LICENSE에 명시된 조건에 따라 보증 없이 제공됩니다.

저작권자 표기는 digital-101을 사용합니다. 앱 화면에 별도의 제작자 배너를 표시하는
것은 MIT의 필수 조건이 아닙니다. 소스 또는 실행본을 재배포할 때에는 LICENSE와
해당 외부 구성요소의 고지를 함께 보존하세요. 외부 기여자·권리자의 기존 이름을
digital-101로 바꾸면 안 됩니다.

engine/_vendor 아래에서 가져온 코드와 자산은 각 원래 라이선스를 유지합니다.
WhisperLiveKit 계열의 Apache-2.0, OpenAI Whisper 및 관련 MIT 고지 등을 함께
제공하며, 수정한 외부 파일에는 변경 사실과 출처를 표시합니다.
자세한 적용 범위와 원문 위치는 THIRD_PARTY_NOTICES.txt를 참고하세요.

2. 공개할 소스
------------------------------------------------------------
이 LiveSubtitle 폴더를 소스 저장소의 루트로 사용합니다.
  LICENSE                       LiveSubtitle 자체 MIT 라이선스
  README.md / README.txt / SOURCE_RELEASE.txt 안내
  THIRD_PARTY_NOTICES.txt        외부 구성요소 출처·라이선스
  .gitignore                    소스 공개 제외 항목
  build.ps1                     Windows 앱 빌드
  API.txt                       로컬 엔진 API 문서
  src/                          C# WPF 앱 소스
  engine/                       Python 엔진·requirements.txt·테스트
  engine/_vendor/                외부 코드·필수 자산·라이선스·출처 기록
  0_사용법/                     사용자 안내
  models/asr/qwen3-asr-1.7b/     검증 버전의 설정·토크나이저·원문 고지
  models/asr/whisper-large-v3-turbo/ 검증 버전의 설정·토크나이저·원문 고지
  models/translation/모델다운로드.md 번역 모델 다운로드 안내

engine/_vendor 안의 LICENSE 파일, 출처 기록, tokenizer 및 mel-filter 자산도
필요한 소스 배포 항목입니다. models/의 대형 가중치와 혼동해 빼지 마세요.

3. 공개 대상에서 제외하는 로컬 파일
------------------------------------------------------------
.gitignore에는 다음 항목을 제외하도록 설정했습니다.
  config/       API 키, 로컬 연결 토큰, 개인 설정과 용어집
  logs/         전사·번역 기록 및 진단 로그
  models/       위에서 명시한 부속 파일·고지를 제외한 모든 모델 파일
  runtime/      Python·CUDA·llama.cpp 등 설치된 실행 환경
  validation/   테스트 영상·화면·전사 결과
  runtime-packages.txt  개인 로컬 wheel 경로가 포함된 설치 기록
  exe/dll/pdb, deps/runtimeconfig JSON, bin/obj 및 캐시
  LiveSubtitle.md, 전사모델비교.md 등 로컬 작업·시험 기록

모델 가중치(.safetensors, .bin, .pt, .gguf 등)는 포함하지 않습니다.
루트 공개 목록 및 모델 폴더별 허용 목록으로 예상하지 못한 파일도 제외합니다.

.gitignore는 Git의 새 파일 추가를 거르는 설정이며 폴더 전체 ZIP에는 적용되지
않습니다. 이미 추적된 파일이나 과거 커밋도 지우지 않습니다. 처음 공개할 때에는
Git에 포함될 파일 목록을 확인하고, 현재 실행 폴더 전체를 그대로 업로드하지 마세요.
현재 config 파일을 예제 설정으로 복사하지 말고 앱의 기본 설정을 사용하세요.

모델은 사용자가 공식 배포처에서 별도로 내려받아 사용하도록 안내합니다.
다운로드 링크와 배치 방법은 0_사용법/사용법.md에 있습니다.
Qwen3-ASR와 HY-MT2는 Apache-2.0, Whisper는 MIT이며,
TranslateGemma와 MiLMMT에는 Gemma Terms of Use가 적용됩니다.
모델의 별도 약관은 앱의 MIT 라이선스로 대체되지 않습니다.

4. 개발 환경과 빌드
------------------------------------------------------------
Windows x64, .NET 10 SDK, Python 3.12 환경을 기준으로 합니다.
현재 로컬 음성 인식 경로는 NVIDIA CUDA GPU를 전제로 합니다.

앱 루트에서 Windows 화면 소스를 빌드합니다.
  powershell -ExecutionPolicy Bypass -File .\build.ps1

이 명령은 .NET 앱을 빌드합니다. Python·llama.cpp·모델까지 자동으로 설치하는
명령은 아닙니다. 엔진 의존성은 engine/requirements.txt에 지정되어 있습니다.
해당 Python 3.12 환경에서 다음 명령으로 설치할 수 있습니다.
  python -m pip install -r engine/requirements.txt

소스 복제본에는 위 두 ASR 모델의 설정·토크나이저가 포함됩니다. README와 각
모델 폴더의 모델다운로드.md에 따라 해당 버전의 가중치를 추가하세요.
다른 모델은 그 모델에 필요한 부속 파일도 함께 준비합니다. 번역 엔진은 runtime/llama의
llama-server.exe와 그 릴리스에 포함된 DLL을 사용합니다. 출처는 고지 문서에 있습니다.
앱의 자동 실행용 Python은 runtime/python/python.exe 위치에 구성합니다.
단순히 소스 저장소를 복제했다고 내장 런타임이 준비되는 것은 아닙니다.

엔진을 개발용 Python 3.12 환경에서 직접 실행할 때:
  python engine/server.py --root . --port 17865

테스트 의존성 설치 및 엔진 테스트:
  python -m pip install pytest pytest-asyncio
  python -m pytest engine/tests -q -p no:cacheprovider

5. 실행본을 별도로 배포할 때
------------------------------------------------------------
이 소스 공개 설정은 모델 가중치와 실행 환경을 포함하지 않는 범위입니다.
실행본에 Python, .NET, PyTorch, llama.cpp, NVIDIA 또는 FFmpeg 라이브러리를 넣어
공개한다면 실제 포함 버전의 LICENSE/NOTICE와 재배포 조건도 함께 충족해야 합니다.
특히 NVIDIA 파일에는 별도 재배포 약관이 있으며, 현재 PyAV 설치에는 x264/x265
DLL도 있어 FFmpeg가 보고하는 LGPL 표기만으로 전체 번들을 판단할 수 없습니다.
해당 빌드의 소스 제공 등 필요한 조치는 실행본 공개 전에 따로 확인해야 합니다.

루트 LICENSE만 추가했다고 모든 외부 바이너리와 모델까지 MIT가 되는 것은 아닙니다.
원문·저작권 고지를 보존하고, 수정한 외부 코드의 변경 기록도 함께 배포하세요.
