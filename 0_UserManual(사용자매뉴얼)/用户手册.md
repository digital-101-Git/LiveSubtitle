# LiveSubtitle 用户手册

[한국어](사용자매뉴얼.md) · [English](UserManual.md) · 中文 · [日本語](ユーザーマニュアル.md)

## 首次使用（只有应用文件）：运行前的设置

**如果没有模型文件，请先下载模型，并放入指定文件夹。** 以下路径均以包含 `LiveSubtitle.exe` 的应用文件夹为基准。

本手册假定可运行的应用及其运行时环境已准备就绪。如果只下载了 GitHub 上的源代码，请先按照[开发环境与构建说明](../SOURCE_RELEASE.txt)准备应用和运行环境。

1. 从下方的**已验证模型下载**表中，下载 **1 个本地语音识别模型和 1 个翻译模型**。
2. 将下载的文件放入下列位置。如果文件夹不存在，请使用相同名称创建。

| 下载的模型 | 存放位置 |
|---|---|
| Qwen3-ASR-1.7B | `models/asr/qwen3-asr-1.7b/` |
| Whisper large-v3-turbo | `models/asr/whisper-large-v3-turbo/` |
| 翻译模型的 `.gguf` 文件 | `models/translation/` |

提供的 Qwen、Whisper 文件夹中已包含配置和分词器。请将 Qwen 的 `model.safetensors`、Whisper 的 `model.bin` 直接放入上述对应文件夹。翻译模型只需将 `.gguf` 文件**保留原始文件名**放入即可。

3. 运行 **LiveSubtitle.exe**，分别选择两个模型，然后点击**准备模型**。准备完成后，按照下方步骤开始显示直播字幕。

## 使用步骤

1. 运行应用文件夹中的 **LiveSubtitle.exe**。无需另外启动 Ollama 或 Python。
2. 在**音频来源**中选择正在播放的 Chrome、Edge、**系统全部声音**或**麦克风 · 设备名称**。如果刚连接了麦克风，请点击列表旁的刷新按钮。
3. 选择**本地语音识别**，然后选择语音识别模型和翻译模型。
4. 在**输入语言**中指定韩语、英语、中文或日语。选择自动检测时，模型将自行判断语言。
5. 在正下方的**翻译语言**中选择韩语、英语、中文或日语。默认值为**韩语**，下次启动时会保留所选设置。
6. **准备模型**完成后，点击**开始实时字幕**。

- 右上角的 **Language** 可将界面语言切换为 **한국어 · English · 中文 · 日本語**。菜单、说明文字以及输入语言和翻译语言列表中的名称会立即更新，下次启动时仍会保留。字幕运行期间也可以切换；已选的输入语言、翻译语言和实际字幕内容不会改变。
- 更改音频来源、模型、输入语言或翻译语言前，请先点击**停止**。输入语言与翻译语言相同时，会直接将识别出的原文作为字幕显示。
- **语音确认方式**中的**默认**使用默认的识别与显示方式。**重复确认（较慢）**会比较多次识别结果后再显示，因此可能增加延迟，且仍可能存在识别错误。
- 麦克风模式使用所选输入设备的声音。如果没有输入，请检查设备连接和 Windows 的麦克风访问权限。麦克风字幕默认显示在显示器上，可编辑其位置和大小。
- 显示字幕期间，应用必须持续运行。关闭窗口后，应用会留在系统托盘中；要结束运行，请选择**完全退出**。
- **最近字幕**中的译文和原文为只读文本。可以用鼠标选中文字，再按 **Ctrl+C** 复制。
- 点击顶部的**清除翻译记录**，会删除 `logs` 文件夹中的翻译记录、日志文件以及界面上的最近字幕。正在运行的字幕会继续处理，之后的新记录也会继续保存。未能删除的文件会显示在运行日志中。
- 如需使用 Gemini 转录，请选择 **Gemini Live** 并输入 API 密钥。所选音频来源的声音会发送给 Google，翻译则由所选的本地模型处理。

## 语音识别提示

提示功能用于向语音识别模型提供**角色姓名的原文写法**，有助于减少因发音相似而将姓名识别为其他文字的错误。此功能**仅适用于本地 Qwen3-ASR**；姓名如何译为所选翻译语言，由翻译模型决定。

1. 如果字幕正在运行，请点击**停止**。
2. 在**语音识别提示 · 可选**中，**使用原语言输入姓名，每行一个**。
3. 点击**保存语音识别选项**，然后点击**开始实时字幕**。

**如果最近字幕的原文中出现了人名**，可以用鼠标选中该姓名，按 **Ctrl+C** 复制，再到提示输入框中按 **Ctrl+V** 粘贴。每个姓名单独一行；如果姓名识别有误，请改为正确的原文写法后再保存。

示例中文视频中的角色姓名输入示例：

```text
顧小糖
陸擎淵
```

- 像上面的示例一样，只需输入姓名，无需添加编号、引号或韩语解释。
- 请填写当前直播中实际出现的姓名；切换到其他直播时，应根据需要修改。
- 最多 **32 个**姓名，每个姓名最多 **48 个字符**，总计最多 **512 个字符**。
- 留空时，不使用提示进行识别。填写姓名并不能保证每次都准确识别。

## 字幕位置

- 默认使用**显示在浏览器上**。对于没有菜单的弹出窗口，请使用**显示在显示器上**。
- 开启**编辑字幕位置和大小**后，可以拖动字幕或调整大小。位置和大小会在下次启动时保留。调整完成后，请关闭编辑。
- 点击**显示在浏览器上 / 显示在显示器上**，会将位置和大小恢复为默认值。
- 显示器模式的默认位置为水平居中，字幕底边位于屏幕高度的 95% 处。

## 模型文件存放位置

```text
LiveSubtitle/
├─ LiveSubtitle.exe
├─ models/
│  ├─ translation/            翻译用 .gguf 文件
│  └─ asr/
│     ├─ qwen3-asr-1.7b/      Qwen 模型、配置和分词器文件
│     └─ whisper-large-v3-turbo/  Whisper 模型、配置和分词器文件
└─ 0_UserManual(사용자매뉴얼)/
   ├─ 사용자매뉴얼.md          한국어
   ├─ UserManual.md            English
   ├─ 用户手册.md              中文
   └─ ユーザーマニュアル.md    日本語
```

- 将翻译 GGUF 放入 `models/translation`，或通过应用中的**添加翻译模型（GGUF）**添加。应用会根据文件名选择专用翻译方式，因此请**保留原始文件名**。
- GGUF 文件出现在列表中，并不代表其翻译输入格式一定兼容。未列入验证列表的专用翻译模型，可能需要在应用中增加对其输入格式的支持。
- 上述 Qwen、Whisper 文件夹中的配套文件与表中链接的固定版本一致。如果使用其他版本或模型，请同时准备该版本所需的配置和分词器。Whisper 的 `model.bin` 用于默认识别方式；`.pt` 文件仅在使用 Whisper AlignAtt 实验功能时需要另行准备。
- 放入模型后，重新启动应用或点击**重新连接**，然后从列表中选择。MiLMMT、HY-MT2 无需另外设置关闭思考模式。
- 迁移到其他电脑时，可以复制整个应用文件夹，并排除体积较大的 `models` 内容，再通过上述链接重新下载模型。
- 最近 100 条翻译记录保存在 `logs/caption-history.json` 中，包含原文、译文、输入语言及翻译语言。
