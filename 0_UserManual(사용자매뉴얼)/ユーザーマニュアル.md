# LiveSubtitle ユーザーマニュアル

## 初めて使う方（アプリのみお持ちの場合）：起動前の設定

**モデルファイルがない場合は、まずモデルをダウンロードし、指定のフォルダーに配置してください。** 以下のパスは、`LiveSubtitle.exe` があるアプリフォルダーを基準としています。

この説明は、実行用アプリとランタイムが用意されていることを前提としています。GitHub からソースコードのみを取得した場合は、先に[開発環境・ビルド手順](../SOURCE_RELEASE.txt)に従ってアプリと実行環境を準備してください。

1. 下の「**動作確認済みモデルのダウンロード**」表から、ローカルの**音声認識モデルを 1 つ、翻訳モデルを 1 つ**ダウンロードします。
2. ダウンロードしたファイルを以下の場所に配置します。フォルダーがない場合は、同じ名前で作成してください。

| ダウンロードしたモデル | 配置先 |
|---|---|
| Qwen3-ASR-1.7B | `models/asr/qwen3-asr-1.7b/` |
| Whisper large-v3-turbo | `models/asr/whisper-large-v3-turbo/` |
| 翻訳モデルの `.gguf` ファイル | `models/translation/` |

付属の Qwen・Whisper フォルダーには、設定ファイルとトークナイザーが含まれています。Qwen は `model.safetensors`、Whisper は `model.bin` を上記フォルダーの直下に配置してください。翻訳モデルは、`.gguf` ファイルを**元のファイル名のまま**配置します。

3. **LiveSubtitle.exe** を実行し、両方のモデルをそれぞれ選択して「**モデルを準備**」を押します。準備が完了したら、以下の手順で配信の字幕を開始します。

## 使い方

1. アプリフォルダーの **LiveSubtitle.exe** を実行します。Ollama や Python を別途起動する必要はありません。
2. 「**音声ソース**」で、再生中の Chrome・Edge、「**システム全体の音声**」、または「**マイク · デバイス名**」を選択します。マイクを新しく接続した場合は、一覧の横にある更新ボタンを押してください。
3. 「**ローカル音声認識**」を選択し、音声認識モデルと翻訳モデルを選びます。
4. 「**入力言語**」を韓国語・英語・中国語・日本語から指定します。自動検出を選ぶと、モデルが言語を判定します。
5. すぐ下の「**翻訳先の言語**」で、韓国語・英語・中国語・日本語を選択します。既定値は**韓国語**で、選択した言語は次回起動時にも維持されます。
6. モデルの準備が完了したら、「**リアルタイム字幕を開始**」を押します。

- 右上の **Language** で、画面の言語を **한국어 · English · 中文 · 日本語** に切り替えられます。メニューや説明文、入力言語・翻訳先の言語の一覧がすぐに切り替わり、次回起動時にも維持されます。字幕の実行中にも変更できます。選択済みの入力言語・翻訳先の言語や、実際の字幕の内容は変わりません。
- 音声ソース・モデル・入力言語・翻訳先の言語を変更する場合は、先に「**停止**」を押してください。入力言語と翻訳先の言語が同じ場合は、認識した原文を字幕として表示します。
- 「**音声の確定方式**」の「**標準**」は、通常の認識・表示方式です。「**繰り返し確認（低速）**」は複数の認識結果を比較してから表示するため、遅延が増える場合があります。また、認識の誤りが残る場合もあります。
- マイクモードでは、選択した入力デバイスの音声を使用します。音声が入力されない場合は、デバイスの接続と Windows のマイクへのアクセス許可を確認してください。マイクの字幕は既定でモニターに表示され、位置とサイズを編集できます。
- 字幕を表示している間は、アプリを起動したままにしてください。ウィンドウを閉じてもトレイで動作を続けます。終了するには「**完全に終了**」を選択します。
- 「**最近の字幕**」の翻訳文と原文は読み取り専用です。マウスで文字を選択し、**Ctrl+C** でコピーできます。
- 上部の「**翻訳履歴を削除**」を押すと、`logs` フォルダーの翻訳履歴・ログファイルと、画面の最近の字幕を削除します。実行中の字幕処理は継続し、その後の新しい履歴は再び保存されます。削除できなかったファイルは進行ログに表示されます。
- Gemini で文字起こしを行うには、**Gemini Live** を選択して API キーを入力します。選択した音声ソースの音声は Google に送信され、翻訳は選択したローカルモデルが処理します。

## 音声認識のヒント

ヒントは、音声認識モデルに**登場人物の名前の原語表記**を伝える機能です。発音が似ているために名前を別の文字で書き起こしてしまう誤りを減らせる場合があります。**ローカルの Qwen3-ASR にのみ適用**されます。選択した翻訳先の言語で名前をどのように表記するかは、翻訳モデルが判断します。

1. 字幕を実行中の場合は「**停止**」を押します。
2. 「**音声認識のヒント · 任意**」に、名前を**その言語の原語表記で、1 行に 1 つずつ**入力します。
3. 「**音声認識の設定を保存**」を押してから、「**リアルタイム字幕を開始**」を押します。

**最近の字幕の原文に登場人物の名前が表示されたら**、マウスでその名前を選択して **Ctrl+C** でコピーし、ヒント欄に **Ctrl+V** で貼り付けてください。名前ごとに改行し、誤認識された名前は正しい原語表記に修正して保存してください。

サンプルの中国語動画に登場する名前の入力例：

```text
顧小糖
陸擎淵
```

- 上の例のように、名前だけを入力してください。番号・引用符・韓国語の説明を付ける必要はありません。
- その配信に実際に登場する名前を入力し、別の配信に切り替えた場合は必要な名前に変更してください。
- 最大 **32 件**、名前 1 つにつき **48 文字**、全体で **512 文字**まで入力できます。
- 空欄の場合はヒントなしで認識します。入力した名前が必ず正しく認識されるわけではありません。

## 字幕の位置

- 既定値は「**ブラウザーに表示**」です。メニューのないポップアップでは「**モニターに表示**」を使用してください。
- 「**字幕の位置とサイズを編集**」を有効にして、字幕をドラッグするかサイズを調整します。位置とサイズは次回起動時にも維持されます。調整が終わったら編集を無効にしてください。
- 「**ブラウザーに表示 / モニターに表示**」を押すと、位置とサイズが既定値に戻ります。
- モニター表示の既定位置は左右中央で、字幕の下端が画面の高さの 95% に来る位置です。

## モデルファイルの配置先

```text
LiveSubtitle/
├─ LiveSubtitle.exe
├─ models/
│  ├─ translation/            翻訳用の .gguf ファイル
│  └─ asr/
│     ├─ qwen3-asr-1.7b/      Qwen のモデル・設定・トークナイザーファイル
│     └─ whisper-large-v3-turbo/  Whisper のモデル・設定・トークナイザーファイル
└─ 0_UserManual(사용자매뉴얼)/
   ├─ 사용자매뉴얼.md          韓国語
   ├─ UserManual.md            英語
   ├─ 用户手册.md              中国語
   └─ ユーザーマニュアル.md    日本語
```

- 翻訳用 GGUF は `models/translation` に配置するか、アプリの「**翻訳モデル追加 (GGUF)**」で追加します。専用の翻訳方式はファイル名で選ばれるため、**元のファイル名を維持**してください。
- GGUF ファイルが一覧に表示されることと、そのモデルに合った翻訳方式で動作することは別です。動作確認済みの一覧にない専用翻訳モデルは、その入力形式に合わせたアプリ側の対応が別途必要になる場合があります。
- 上記 Qwen・Whisper フォルダーの付属ファイルは、表のリンク先の固定バージョンに対応しています。別のバージョンやモデルを使用する場合は、そのバージョンに必要な設定ファイルとトークナイザーも用意してください。Whisper の `model.bin` は通常の認識に使用します。`.pt` ファイルは、Whisper AlignAtt の実験機能にのみ別途必要です。
- モデルを配置したらアプリを再起動するか「**再接続**」を押し、一覧から選択してください。MiLMMT・HY-MT2 では、思考モードを無効にする設定を別途行う必要はありません。
- 別の PC に移す際は、アプリフォルダー全体をコピーしてください。容量の大きい `models` の内容はコピーから除外し、上記リンクから再ダウンロードしても構いません。
- 直近 100 件の翻訳履歴は、原文・翻訳文・入力言語・翻訳先の言語とともに `logs/caption-history.json` に保存されます。
